# heygen-tts

Python tool: HeyGen voice studio → MP3, without video credits.

- Full agent instructions: [SKILL.md](SKILL.md)
- CLI: `python scripts/heygen_tts.py --help`
- Offline test: `python scripts/selftest.py`
- User documentation: [README.md](README.md)

Guardrail: never click Generate / Render Scene in the HeyGen video editor (20 credits/minute). The "Generate" button of the voice studio produces the free audio preview.
