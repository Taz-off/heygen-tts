# heygen-tts

Outil Python : studio de voix HeyGen → MP3, sans crédit vidéo.

- Instructions complètes pour l'agent : [SKILL.md](SKILL.md)
- CLI : `python scripts/heygen_tts.py --help`
- Test hors-ligne : `python scripts/selftest.py`
- Documentation utilisateur : [README.md](README.md)

Garde-fou : ne jamais cliquer sur Generate / Render Scene dans l'éditeur vidéo HeyGen (20 crédits/minute). Le bouton « Générer » du studio de voix, lui, produit l'aperçu audio gratuit.
